 SB 1522 
 
 
 By Senator Rodriguez 
 
 
 A bill to be entitled 
 An act relating to security of state information technology systems; creating s. 282.3187, F.S.; requiring state agencies to deploy certain cloud native cybersecurity platforms; requiring state agencies to use platforms that meet specified criteria; requiring the state chief information officer to brief legislative committees on specified information by a specified date; providing an effective date. 
 
 
 
 Be It Enacted by the Legislature of the State of Florida: 
 
 Section 1. Section 282.3187, Florida Statutes, is created to read: 
 
 282.3187 Security of state technology systems. -- 
 
 
 (1) As the state continues to implement its cloud-first policy and transition agency applications and datasets into modern cloud environments, each state agency shall deploy cloud native cybersecurity platforms designed to safeguard cloud and hybrid infrastructure. 
 
 
 (2) State agencies shall use platforms that: 
 
 
 (a) Provide unified visibility across multi-cloud and hybrid environments; 
 
 
 (b) Enable continuous posture management, misconfiguration detection, and automated risk prioritization to reduce cloud attack surface; 
 
 
 (c) Support secure cloud application development, including code-to-runtime protection; 
 
 
 (d) Deliver real-time threat detection and response within cloud workloads and identities; and 
 
 
 (e) Provide automated compliance monitoring across state and federal cybersecurity frameworks. 
 
 
 (3) By October 1, 2026, the state chief information officer shall brief the appropriate committees of the Legislature on all of the following: 
 
 
 (a) The state&#39;s progress in continuously monitoring the security of all cloud, on-premises, and hybrid application environments. 
 
 
 (b) The identification of systemic risks and misconfigurations across agency cloud deployments. 
 
 
 (c) The development of a future artificial intelligence security roadmap, including recommendations for securing artificial intelligence systems, models, and automated decisionmaking tools used by state agencies. 
 
 
 Section 2. This act shall take effect July 1, 2026.
