## Summary (verify for accuracy)

China's first binding GenAI regulation requires CAC licensing before public deployment of large language models. Prohibits content violating socialist core values, mandates user registration, requires training data security and personal information protection, and mandates AI-generated content labelling. Security assessment required for LLMs before public release.

## Key Obligations (verify completeness and accuracy)

- AI-generated content must be labeled as AI-generated
- Service providers must conduct security assessment before launch
- Training data must not include prohibited content (defined broadly)
- Providers responsible for content generated by their systems
- Mechanisms to handle user complaints about generated content
- Security filing with CAC for public-facing services
