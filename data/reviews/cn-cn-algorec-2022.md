## Summary (verify for accuracy)

First globally binding regulation of algorithmic recommendation systems. Requires platforms with 1M+ users to register recommendation algorithms, offer non-personalized options, enable user preference modification, conduct risk assessments, and report to regulators. Prohibits discriminatory pricing and addictive design patterns targeting minors.

## Key Obligations (verify completeness and accuracy)

- Users have right to opt out of personalised algorithmic recommendations
- Prohibition on using algorithms to create addictive features for minors
- Prohibition on price discrimination using personal characteristics
- Gig economy platforms must explain how work allocation algorithms function
- Large platforms must file algorithm registry with CAC
