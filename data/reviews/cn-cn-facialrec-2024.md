## Summary (verify for accuracy)

Regulates the application of facial recognition technology in China. Requires explicit consent for facial recognition, limits its use to genuinely necessary scenarios, mandates security assessments for systems processing large volumes of facial data, and prohibits unlawful use for personal identification without consent. Public-space deployments require state approval and must display notices.

## Key Obligations (verify completeness and accuracy)

- Obtain explicit written consent before collecting facial data
- Display visible notices when facial recognition is deployed in public
- Conduct security assessments for systems processing 100,000+ people
- Prohibit facial recognition in hotel rooms, changing rooms, restrooms
- Delete facial data when original purpose is fulfilled
